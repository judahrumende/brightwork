## Setup

Run the database migration and restart Brightwork. Use the Browser, Social, or Ads dock shortcut, then select the relevant Growth tab. Research has its own shortcut.

- Set `SEARXNG_BASE_URL` for lead searches and cited Research. `RESEARCH_MODEL_TIMEOUT_SECONDS` defaults to 10 seconds for each model call. An increased value also extends the total request deadline.
- Set `GROWTH_WORKSPACE_ID` to the Brightwork workspace UUID shown in its URL. Provider access is scoped to this workspace. Leave fields blank until you are ready to connect each provider.
- For Facebook publishing, set `GROWTH_META_PAGE_ID` and `GROWTH_META_PAGE_TOKEN` using a Page access token with permission to publish. Ask Pip for a social draft in Build or save one in Social, approve it, then confirm publication to the visible Page ID. [Meta Page Feed](https://developers.facebook.com/docs/graph-api/reference/page/feed/)
- For Meta campaigns and wallet reporting, set `GROWTH_META_AD_ACCOUNT_ID` to the numeric account ID and provide `GROWTH_META_AD_TOKEN` with access to manage that account. Brightwork allows pausing campaigns. Activation is gated on budget enforcement in an approved test environment. [Meta Ad Account](https://developers.facebook.com/docs/graph-api/reference/ad-account/)
- For the Google listing, set `GROWTH_GOOGLE_LOCATION_ID` to the numeric location ID and provide `GROWTH_GOOGLE_ACCESS_TOKEN` with `business.manage` consent and access to the Business Information API. Refresh expired access tokens on the server. [Google Business Information API](https://developers.google.com/my-business/reference/businessinformation/rest/v1/locations/patch)

## Further rollout

A funded wallet requires an agreed payment and settlement flow with the ad platform, an immutable ledger, verified payment webhooks, reconciliation and refund handling. Before adding top-ups, verify how collected funds would settle advertising charges. Additional social networks and ad platforms each need their own provider integration and account authorization. Embedded interactive browsing and automatic lead enrichment would require a separate browsing runtime and explicit data sources.
