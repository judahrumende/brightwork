# Remaining Brightwork delivery plan

Each milestone ships through a private PR with a frozen install, build, migrations, unit and integration tests, and relevant browser scenarios. Provider requests in CI use synthetic fixtures. Record live verification separately in progress notes and keep live activation behind explicit configuration.

| Milestone                   | Implementation                                                                                                                                                                                                                                                                                                           | Acceptance evidence                                                                                                                                                                                       |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Two-way SMS                 | Verify a Twilio SMS-capable number in workspace settings, store its credential encrypted, and show its conversation history in Inbox. Signatures bind callbacks to the exact URL and the connected account and phone. A durable send record precedes the provider request. A stable request ID prevents duplicate sends. | Connect, send, receive, update delivery, reconnect and revoke. Exercise incorrect signatures, duplicate and premature callbacks, status reordering, cross-workspace access, opt-outs and ambiguous sends. |
| Social replies              | Add a workspace-scoped Page connection with verified identity. Add a signed comments webhook, read thread context and allow replies to reviewed text. Keep provider send results scoped to the Page and thread.                                                                                                          | Verify incorrect Page and actor, retries, reply threading, disconnected delivery, token replacement and old callback behavior. Record provider permissions and live verification separately.              |
| Stripe Connect              | Use hosted seller onboarding. Track account readiness from signed events. Snapshot each checkout's connected account, currency and amount and reconcile completed payments and refunds idempotently.                                                                                                                     | Exercise incomplete onboarding, wrong account, partial and full refunds, duplicate and reordered events, and sale isolation. Verify a provider-hosted test checkout when access is available.             |
| Referrals                   | Bind a referral once during account setup. Grant credits only after the first qualifying paid invoice. Reverse that grant when the qualifying payment is fully refunded. Use the credit ledger for both entries.                                                                                                         | Cover self-referral, concurrent redemption, repeated payment events, cancellation and refund reversal. Verify attribution survives sign-in and workspace switching.                                       |
| Sales and customer insights | Normalize authoritative Shopify and Connect order facts into workspace-scoped reporting. Keep currencies separate and preserve net/refunded amounts. Apply data minimization to customer identities and report unknown attribution explicitly.                                                                           | Reconcile report totals with fixture source transactions. Test date boundaries, currency, refunds, repeat customers, and workspace isolation.                                                             |
| Metered media               | Add configured image, video and voice adapters separately. Record a unique job, reserve credits before submission, and reconcile completion, ambiguous submissions and failures. Store completed assets under existing workspace access rules.                                                                           | Check balance limits, retries, concurrent jobs, restart recovery, asset access and provider failures. Record each live capability's status independently.                                                 |
| Marketing and SSR           | Inventory marketing paths against the capture kit. Render public content and metadata in initial HTML, hydrate interactive controls and verify public caching boundaries.                                                                                                                                                | Compare rendered pages at desktop and mobile widths, inspect initial HTML without JavaScript, exercise accessibility and navigation, and verify public responses carry no workspace information.          |

Start with SMS and reuse the existing authorization and encrypted credential code. Social can reuse the SMS lifecycle tests as a checklist. Stripe Connect and referral changes depend on distinct payment and entitlement boundaries. Insights follows stable order and refund records from both providers. The current Railway trial prevents staging acceptance until hosting access changes.
